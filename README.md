# Milan Manoj Varghese — Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. Designed for free hosting on GitHub Pages.

## Files
- `index.html` — page content and sections
- `style.css` — dark premium theme and responsive layout
- `script.js` — mobile menu, scroll reveal, and placeholder link handling
- `assets/` — add your profile photo here

## Personalize before publishing
1. Add your photo at `assets/profile-photo.jpg` (JPG format works best).
2. In `index.html`, replace the `href="#"` values for GitHub, LinkedIn, and Email with your real URLs. For email, use `mailto:you@example.com`.
3. Check the project description and update it to match your verified contribution.
4. Optional: change the page title and description in the `<head>`.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `milan-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root. Keep the file names as they are.
3. Open the repository's **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. The page URL will look like `https://YOUR-USERNAME.github.io/milan-portfolio/`.
7. Whenever you update files in the repository, GitHub Pages republishes the site automatically.

## Preview locally
Open `index.html` in a browser. For the most accurate preview, use a local development server or VS Code Live Server.

## Notes
- Do not add passwords, API keys, or private information to a public repository.
- A public GitHub Pages site is viewable by everyone. Visitors cannot edit your website merely by opening its public URL; only people with repository write permissions can change the source.
